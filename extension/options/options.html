LambSafe

Keeps a copy of your deployed Lambda code before you change it in the AWS console.

AWS credentials

LambSafe calls lambda:GetFunction to learn which version is deployed and to download it. Credentials stay in this browser's local extension storage. They are never synced and are only sent to AWS. Use a dedicated IAM user or role with only the policy below.

Minimal IAM policy

    Add credentials

    Credentials are checked with STS GetCallerIdentity, which needs no permissions, to learn their account ID. Saving credentials for an account that already has some replaces the old ones, which is how you refresh expired SSO credentials.

    When to back up

    Every check asks AWS which version is deployed. A download only happens when that exact version (by its CodeSha256 hash) has not been saved before.
